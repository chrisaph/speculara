# Synthetic sample files

Both files contain the same 40 synthetic posts. They are not measurements of an Instagram, Facebook or TikTok account. Sales is a count, not currency. Comments include English and Filipino examples for sentiment and demand testing.

In Speculara, choose **Analyze CSV / Excel data** and select either file. Alternatively, choose **Try with sample data**, then **Import metrics CSV / Excel**. The IDs match the built-in sample's IDs 0–39. Do not import these invented counts into a real profile: use that profile's **Download metrics template** and your own observed values instead.

The files have numeric metric values, distinct post IDs, dates, formats and caption/comment text. No external post URLs are invented. Imported counts, all 15 supported metric pairs, and preserved sample comments were verified for both formats.
